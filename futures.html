Not a futures trade — read-only data, never buys or sells the future. Used only as an extra condition before a NEW option entry: a Call Buy needs the futures quadrant to show Long buildup (price up + OI up over the last ~15 min), a Put Buy needs Short buildup (price down + OI up); otherwise the entry is skipped (reversal closes and EOD force-close are never gated by this). Added 2026-10-26 -- no historical futures OI existed for this project before then, so this is unvalidated; this page exists to build that track record going forward.
Reads futures_log.json from this folder — one entry per paper-trade tick (same 4-min cadence as the option-chain collector), logged by the main paper trader (paper_tick.py), same process as everything else here. Quadrant: price up + OI up = Long buildup (fresh longs), price down + OI up = Short buildup (fresh shorts), OI down on either side = unwinding/covering (existing positions closing, not fresh conviction) = Flat/weak. Threshold: both the price move and the OI move need to be ≥0.5% over the ~15-minute lookback, else classified Flat. Kept for the last 90 days.
